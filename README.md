# Demostración de enlace externo

Sitio estático independiente preparado para desplegar en Vercel. El destino es **https://example.com/**, de prueba y visible en la interfaz.

## Desplegar
1. En Vercel, elige **Add New → Project**.
2. Importa `aaapn777/Occidental-Personas`.
3. Configura **Framework Preset: Other** y despliega sin variables de entorno.

## Cambiar el destino
Edita el atributo `href` del enlace en `index.html` y el texto visible de destino. Mantén ambos coherentes y un aviso claro de independencia.

Esta demo no solicita datos, no usa CAPTCHA y no oculta el destino.
